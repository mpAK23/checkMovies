100% Static & GitHub Pages Ready: ReelWindow runs entirely in your browser using the bundled 230+ movie dataset (movies-data.json) plus live browser CORS APIs for ZIP code lookup, OpenStreetMap cinema locations, and Apple iTunes movie search—no Node server required!

If you also have a TMDB API Key (v3 key or v4 Read Access Token), you can enter it below to merge TMDB's live Now Playing and Upcoming feeds directly in your browser.

How Theatrical Windows Are Estimated: Start dates reflect official theatrical openings. Estimated end dates combine studio release scale (Blockbuster ~60d, Wide ~45d, Mid-Wide ~35d, Limited/Indie ~24d), review rating word-of-mouth hold (±7 to 14 days), and local ZIP code cinema density.
